# Проєкт «Відновлення зображення методами оптимізації» — варіант №4 (Python)

## Запуск
```bash
python3 -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py            # повний прогін, ~40 с
python main.py --fast     # швидший, грубіші сітки для графіків
```
Усе потрапляє в `outputs/`: зображення, графіки, таблиці (`results.md`, `*.csv`) і
`control_check.md` — звірка з контрольними числами варіанта №4 (зараз збігається 42 з 42).

## Структура
| Файл | Що робить |
|---|---|
| `src/variant.py` | параметри варіанта №4 |
| `src/rng.py`, `src/image.py`, `src/metrics.py`, `src/oracle.py` | частина 0: генератор, чисте/зашумлене зображення, MSE/PSNR, оракул-лічильник |
| `src/filters.py` | гаусів і білатеральний фільтри |
| `src/lab1_svenn.py` | лаб. 1: алгоритм Свенна |
| `src/lab2_search.py` | лаб. 2: дихотомія, золотий переріз |
| `src/lab3_nelder_mead.py`, `src/lab3_powell.py` | лаб. 3: Нелдер—Мід, Пауелл (лінійний пошук = Свенн + золотий переріз) |
| `src/operators.py` | grad / div / лапласіан, енергія Тихонова, перевірки операторів, точний розв'язок через ДКП |
| `src/lab4_gradient.py` | лаб. 4: спуск, Армійо, важка кулька, Нестеров (+ дод. завдання: повна варіація) |
| `src/lab5_constrained.py` | лаб. 5: проєкція градієнта (+FISTA), метод штрафів |
| `main.py` | запускає все, обов'язкові досліди, графіки, таблиці |
